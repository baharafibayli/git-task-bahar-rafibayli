# Git və GitHub praktiki tapşırıq

**Ad, soyad:** Bahar Rafibayli
**Qrup:** 845i

## Layihənin qısa izahı
Bu layihə Git və GitHub-ın əsas komandalarını praktikada öyrənmək üçün hazırlanıb. Layihədə sadə HTML səhifə və Python proqramı var. Branch-lərlə işlənib və main branch-ə merge edilib.

## Layihədəki fayllar
- `index.html` - şəxsi məlumatlar olan HTML səhifə
- `app.py` - istifadəçidən ad və yaş alan Python proqramı
- `README.md` - layihə haqqında məlumat

## İstifadə etdiyim Git komandaları
- `git init` - yeni lokal repository yaradır
- `git status` - faylların vəziyyətini göstərir
- `git add .` - dəyişiklikləri staging sahəsinə əlavə edir
- `git commit -m "..."` - dəyişiklikləri commit kimi saxlayır
- `git log --oneline` - commit tarixçəsini qısa göstərir
- `git branch -M main` - branch adını main edir
- `git remote add origin URL` - GitHub repository-ni bağlayır
- `git remote -v` - remote məlumatını göstərir
- `git push` - commit-ləri GitHub-a göndərir
- `git switch -c branch` - yeni branch yaradıb ona keçir
- `git switch main` - main branch-ə keçir
- `git merge branch` - branch-i cari branch ilə birləşdirir
